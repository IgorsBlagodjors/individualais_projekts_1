# Как принять изменения в своём репозитории

Ниже приведён примерный порядок действий, который поможет перенести предложенные правки в ваш GitHub-репозиторий.

## 1. Сохраните текущие изменения локально
Если в рабочей копии уже находятся предложенные правки, убедитесь, что они готовы к коммиту:

```bash
git status
```

## 2. Добавьте файлы в индекс
Отметьте изменённые файлы для включения в коммит:

```bash
git add <путь/к/файлу> [...]
```

Для всех изменённых файлов можно использовать сокращённый вариант:

```bash
git add .
```

## 3. Создайте коммит
Зафиксируйте изменения осмысленным сообщением:

```bash
git commit -m "Краткое описание правок"
```

## 4. Настройте удалённый репозиторий (если ещё не настроен)
Подключите свой GitHub-репозиторий один раз:

```bash
git remote add origin https://github.com/<ваш-логин>/<ваш-репозиторий>.git
```

Проверьте список подключённых удалённых репозиториев:

```bash
git remote -v
```

## 5. Отправьте ветку на GitHub
Запушьте текущую ветку (например, `work`) на GitHub:

```bash
git push -u origin work
```

После первой отправки можно выполнять просто `git push`.

## 6. Создайте pull request (по желанию)
Перейдите на GitHub, откройте свой репозиторий и создайте Pull Request из запушенной ветки в основную.

Следуя этим шагам, вы перенесёте локальные изменения в свой репозиторий и сможете продолжить работу с ними через GitHub.
